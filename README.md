# Instagram Content Automation Bot

A Python-based automation project for managing Instagram content workflows through a Telegram bot.

## Features
- Telegram bot interface for sending content
- File upload workflow
- Cloudinary integration
- Make.com automation scenario
- API-based content processing
- Simple backend logic using Python / FastAPI

## Tech Stack
Python, Telegram Bot API, FastAPI, Make.com, Cloudinary, GitHub

## Purpose
The goal of this project was to reduce manual content posting work and create a clear automation workflow for preparing or publishing Instagram posts.
